# Choose the Microsoft Certification Roadmap in 2026: Fundamentals to Expert

The Microsoft certification roadmap in 2026 is: pick a Fundamentals exam, choose an active Associate credential in the same role family, then pursue Expert only after checking current Microsoft Learn prerequisites. Do not follow old DP-203 roadmaps; DP-203 retired on March 31, 2025, and DP-700 is the current Fabric data engineering path [7][8].

Most roadmaps still optimize for a clean ladder: AZ-900 to AZ-104 to AZ-305, DP-900 to DP-203, AZ-900 to AZ-204, AZ-900 to AZ-500. The better 2026 rule is harsher: never start with a diagram until you have checked the retirement page. Microsoft is moving multiple credentials toward AI-era replacements, and a technically correct path from 2024 can now waste your exam budget [6][9].

![Microsoft certification roadmap diagram showing active 2026 paths from Fundamentals to Associate and Expert credentials.](/img/blogs/2026-07-08-microsoft-certification-roadmap-fundamentals-expert/hero.png)

## Start with the active role family, not the nearest exam code

Microsoft's credential catalog is organized around role families, not a single universal ladder [1]. Active Fundamentals exams in mid-2026 include AZ-900, DP-900, and SC-900. MS-900 (Microsoft 365 Fundamentals) retired on March 31, 2026, and AI-900 (Azure AI Fundamentals) retired on June 30, 2026 — do not start with either [6]. Associate exams validate role execution. Expert credentials validate architecture or senior operating responsibility.

That structure matters because the first exam is often optional. AZ-900 is useful if you are new to Azure vocabulary, pricing, identity, networking, and governance. It is not a hard gate for AZ-104, AZ-204, or AZ-500. The real gate appears later: Microsoft lists AZ-104 as the prerequisite for Azure Solutions Architect Expert [3].

| Career target | Recommended 2026 path | Watch-out |
|---|---|---|
| Azure administrator / architect | AZ-900 -> AZ-104 -> AZ-305 | AZ-104 is the hard prerequisite for AZ-305 [3] |
| Azure developer | AZ-900 -> AZ-204 only if you can finish before July 31, 2026 | AZ-204 is listed to retire July 31, 2026 [6] |
| Azure security engineer | SC-900 or AZ-900 -> AZ-500 only if you can finish before August 31, 2026 | AZ-500 is listed to retire August 31, 2026 [6] |
| Data engineer | DP-900 -> DP-700 | DP-203 is retired [7][8] |
| AI engineer | AI-900 retired June 30, 2026; AI-102 (Azure AI Engineer Associate) also retired June 30, 2026 → browse the Microsoft Learn catalog for the current AI role credential | Both AI-900 and AI-102 are retired [1][6]; verify the current AI path before booking |
| Microsoft 365 administrator | MS-900 retired March 31, 2026 → MS-102 Microsoft 365 Administrator (active) is now the entry credential for the M365 track | MS-900 is retired [6]; browse catalog to confirm any Fundamentals successor before starting [1] |

## Replace DP-203 with DP-700 for data engineering

Do not start DP-203 prep in 2026. Microsoft's DP-203 study guide marks the exam retired on March 31, 2025 [7]. That means "DP-900 -> DP-203" is no longer a current certification path, even if older blog posts, Udemy courses, or team wikis still show it.

The current data engineering path is **DP-900 -> DP-700 Fabric Data Engineer Associate**. Microsoft describes the Fabric Data Engineer credential as an intermediate certification for designing, creating, and managing data engineering solutions in Microsoft Fabric [8]. The official DP-700 training course says the audience is data professionals who work with extraction, transformation, loading, orchestration, and languages such as SQL, PySpark, or KQL [8].

This is not just a code swap. DP-203 was Azure Data Factory, Synapse, Databricks, and data lake architecture in the older Azure data stack. DP-700 shifts the center of gravity to Fabric. If your employer still runs Synapse-heavy workloads, DP-700 may still be the credential that stays visible on a transcript, but your study plan should include the older Azure services as job context rather than as the credential target.

## Treat AZ-204 and AZ-500 as deadline-sensitive, not evergreen

AZ-204 and AZ-500 are still visible certification pages, but Microsoft lists both on the retirement schedule: AZ-204 retires July 31, 2026, and AZ-500 retires August 31, 2026 [4][5][6]. On July 9, 2026, that gives AZ-204 less than a month and AZ-500 less than two months.

That changes the recommendation. If you already studied AZ-204, have practice scores above the pass line, and can book a near-term slot, finishing may still make sense. If you are starting from zero, the smarter move is to read Microsoft's AI-skills transition post and watch the replacement credentials instead [9]. Microsoft positions the new Azure AI Cloud Developer Associate as the replacement direction for Azure Developer, and Cloud and AI Security Engineer Associate as the replacement direction for Azure Security Engineer [9].

For security learners, this also means SC-series credentials deserve more weight. SC-900 remains the cleaner foundation for identity, compliance, and Microsoft security vocabulary. SC-300 and SC-400 then map more directly to identity and information protection work than AZ-500 does for someone starting after the retirement notice.

Before you pay for AZ-204 or AZ-500, check Microsoft's retirement page on the same day you book. Microsoft says retirement listings are subject to change, and the listed dates are July 31, 2026 for AZ-204 and August 31, 2026 for AZ-500 [6].

## Budget and timeline should drive the path

The practical cost model is simple: plan for one proctored exam fee per credential attempt, then add time for practice tests and hands-on labs. Microsoft exam prices vary by country and exam, but many role-based exams are commonly listed around the USD 165 range in the United States when scheduled through the Microsoft/Pearson VUE flow. Verify the exact fee on the exam page before booking because regional taxes, offers, and voucher programs can change the checkout price [1].

Use this timeline if you are choosing a path from scratch:

- **Fundamentals:** 1-3 weeks if you are new to the product family; shorter if you already use Azure, Microsoft 365, or security tooling daily.
- **Associate:** 6-10 weeks for AZ-104, MS-102, DP-700, or similar role exams if you build labs instead of only watching videos.
- **Expert:** 8-12 additional weeks after the Associate credential, because architecture exams test tradeoffs, not memorized service names.

Free Microsoft Learn modules are enough for the first pass through objectives. Paid courses become useful when they add labs, timed practice, or instructor feedback. For Azure architecture, pair the official AZ-104 and AZ-305 pages with hands-on resource group, networking, storage, identity, and monitoring exercises [2][3]. For Fabric, build one lakehouse, one pipeline, one notebook transformation, and one security model before attempting DP-700 [8].

## Renew annually before the credential becomes stale

Microsoft associate, expert, and specialty credentials renew on an annual cycle. Renewal is not the same as booking the full exam again: Microsoft Learn renewal assessments are free when you are eligible, and renewal pages explain that you can show current knowledge by passing the online assessment [7][10].

The renewal rule is especially important for Expert credentials. If an Expert certification depends on an Associate prerequisite, keep the base credential current first. Letting the Associate credential expire can create a transcript problem even if the Expert badge still appears familiar to hiring managers.

Use this lightweight renewal workflow:

1. Add the certification expiry date to your calendar on the day you pass.
2. Create a second reminder six months before expiry, when renewal assessments typically become relevant.
3. Read the renewal page and changed skills outline before attempting the assessment.
4. Pass the free renewal assessment before the expiry window closes.

## Pick the path that survives the next retirement page

The safest 2026 roadmap is not "start at Fundamentals and climb every rung." It is "pick the role family, remove retired exams, check imminent retirements, then book the credential that will still matter when your study window ends." For infrastructure, AZ-104 -> AZ-305 remains the clearest Expert route. For data, DP-700 replaces DP-203. For developer and security tracks, AZ-204 and AZ-500 are now short-window decisions, not default recommendations.
