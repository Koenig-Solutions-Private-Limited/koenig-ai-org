## Definition
Context injection is a technique used to provide a Large Language Model (LLM) with external data or background information that was not part of its original training set. By inserting this context directly into the prompt (often via a Retrieval-Augmented Generation, or RAG, pipeline), the model can answer questions about specific documents, user history, or real-time data while leveraging its existing reasoning capabilities.
