# Data Residency

**Data Residency** (or data localization) is the requirement that data be stored and processed within a specific geographic location (e.g., within the EU for GDPR compliance). MCP connectors help address data residency by allowing models to query data where it lives without requiring bulk exports to a central LLM provider's data center.
