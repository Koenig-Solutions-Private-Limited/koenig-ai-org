## Definition
Active learning is a specialized approach in machine learning where the learning algorithm is able to interactively query an oracle—often a human—to label data that the model is uncertain about. This is particularly valuable in scenarios where unlabeled data is abundant, but labeling is expensive or time-consuming. By focusing on the most informative samples, active learning can significantly reduce the number of labeled examples required to reach high performance levels.
