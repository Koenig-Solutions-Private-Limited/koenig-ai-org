## Definition
An agentic loop is a fundamental architectural pattern for autonomous agents. It consists of a continuous, iterative cycle where the agent observes the current state, plans its next action, executes that action using tools or models, observes the result, and reflects on whether the goal has been achieved. This loop allows the agent to recover from failures, adapt to new information, and navigate long-running tasks without constant human intervention.
