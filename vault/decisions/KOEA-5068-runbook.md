# KOEA-5068 Daily-Synthesis Stale Guard Audit Runbook

## Purpose
Audit the last 24 hours of stale-superseded daily-synthesis auto-cancellations generated by `scripts/koenig-cron-driver.py`.

## Last-24h audit query
Use the company-scoped issues search and filter for the stale-guard marker:

```bash
curl -sS -H "Authorization: Bearer $PAPERCLIP_API_KEY" \
  "$PAPERCLIP_API_URL/api/companies/$PAPERCLIP_COMPANY_ID/issues?limit=100&status=cancelled&q=daily-synthesis-stale-guard"
```

## Review checklist
For each cancelled issue returned by the query, inspect the cancellation comment and verify it contains all of:

- `[daily-synthesis-stale-guard]`
- `superseded by <identifier>`
- `evidence: vault/research/_daily/YYYY-MM-DD.md` or `evidence: vault/research/_synthesis/...`
- `evaluated_at: <UTC timestamp>`

## Escalation
Search blocked issues for stale-guard triage comments and escalate any candidate that still has a triage comment older than 24 hours.

```bash
curl -sS -H "Authorization: Bearer $PAPERCLIP_API_KEY" \
  "$PAPERCLIP_API_URL/api/companies/$PAPERCLIP_COMPANY_ID/issues?limit=100&status=blocked&q=daily-synthesis-stale-guard"
```

If unresolved after 24h, escalate to Chief Research with the issue identifier, triage reason, and most recent evaluation timestamp.
