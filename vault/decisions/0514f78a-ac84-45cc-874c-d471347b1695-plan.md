# Plan: course chapter navigation — kill dead anchors, give every chapter a real URL

## Goal

Every course chapter has a unique, externally linkable URL that resolves to a real page (not an in-page fragment). The course landing page links to those URLs from its chapter index. Search engines and AI ingestion (JSON-LD `hasPart`, sitemap, `llms-full.txt`) advertise those URLs instead of the current `#ch-<int>` fragments that don't exist in the rendered DOM.

Success is observable as:

1. `curl https://academy.kspl.tech/learn/<slug>/<chapter-slug>` returns HTTP 200 with chapter prose for every published chapter.
2. JSON-LD on the course landing emits `hasPart[].url = https://academy.kspl.tech/learn/<slug>/<chapter-slug>` (no `#ch-N`).
3. The chapter index on the course landing navigates to the per-chapter route, not to an in-page anchor.
4. Sitemap and `/llms-full.txt` enumerate every per-chapter URL.

## Risk

- **Chapter slug collisions.** `courses.ts` derives `chapter.slug` from `file.replace(/^\d+-|\.md$/g, "")`. If two chapters in the same course resolve to the same slug (e.g. `01-foo.md` and `02-foo.md`), Next's `generateStaticParams` will throw. **Mitigation:** add a defensive `assert(uniqueBy(course.chapters, c => c.slug))` in `getCourse` and surface a build-time error with the offending slug; Content Author can rename the file.
- **Lost in-page anchors.** External backlinks to `#ch-01-...` anchors stop scrolling. **Mitigation:** the per-chapter route covers any reasonable "deep link" use case; if an existing inbound link uses the integer anchors (`#ch-0`) those were already dead. Optionally add a small client-side script on the landing that redirects `#ch-<padded>-<slug>` to `/learn/<slug>/<chapter-slug>` — recommend as a follow-up, not part of this ticket.
- **Nova grounding regression.** Removing inline chapter rendering means `groundingBody` is no longer present in the rendered HTML. It is currently passed to `CoursePageClient` as a prop, so JS-grounded answers still work; SSR HTML grounding (if any non-JS reader) is lost. **Mitigation:** verify in step 8 that Nova answers on the landing still cite chapter content; if not, render `groundingBody` inside a `<script type="text/plain">` or `<noscript>` block.
