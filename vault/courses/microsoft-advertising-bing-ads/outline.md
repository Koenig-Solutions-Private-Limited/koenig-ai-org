## Chapter 1: Microsoft Advertising Platform Orientation: Interface, Account Structure & the Google Ads Migrant's Mindset

**Duration:** ~40 min
**Learning objectives:**
- Navigate the Microsoft Advertising dashboard and locate Campaigns, Ad Groups, Reports, and Billing sections
- Configure account-level settings including time zone, currency, tracking template, and auto-tagging
- Identify the five key structural differences between Microsoft Advertising and Google Ads
- Create a new Search campaign skeleton with correct campaign-level and ad group-level settings

**Key concepts:** UI navigation, account hierarchy, network reach comparison, auction mechanics, LinkedIn targeting overview, Copilot surfaces, import fidelity, campaign skeleton setup

**Hands-on exercise:** Create a new Microsoft Advertising account and configure all account-level settings. Build one Search campaign skeleton (no live ads) with correct campaign settings and one ad group, documenting the five structural differences encountered.

---

## Chapter 2: Importing & Auditing Google Ads Campaigns into Microsoft Advertising

**Duration:** ~45 min
**Learning objectives:**
- Execute a scheduled Google Ads import via the Microsoft Advertising Import Center and verify import status
- Audit imported campaigns for paused items, missing ad extensions, and bid strategy incompatibilities
- Adjust device bid modifiers and match types to reflect Microsoft's desktop-heavy, lower-competition environment
- Apply the post-import performance tips surfaced by the Import Center to at least three campaign settings

**Key concepts:** Import Center workflow, scheduled imports, import audit checklist, bid strategy incompatibilities, device modifier adjustments, match type calibration

**Hands-on exercise:** Import a sample Google Ads campaign (instructor-provided export), run the audit checklist against it, fix the top three breakage points, and document the post-import modification log.

---

## Chapter 3: Keyword Strategy & Responsive Search Ads for the Microsoft Audience

**Duration:** ~50 min
**Learning objectives:**
- Research keywords using the Microsoft Advertising Keyword Planner and identify volume and CPC differences versus Google Ads estimates
- Build tightly themed ad groups for travel intent categories with appropriate match types
- Write RSAs with 15 headlines and 4 descriptions, enabling autogenerated assets and avoiding over-pinning
- Evaluate asset performance labels and replace underperforming headlines within a two-week review cycle

**Key concepts:** Keyword Planner, Bing demographic skew, travel intent taxonomy, match type strategy, RSA structure, autogenerated assets, ad strength, asset performance labels

**Hands-on exercise:** Use Keyword Planner to build a 50-keyword plan for a travel brief (flights + hotels + holiday packages). Write one complete RSA with 15 headlines and 4 descriptions. Annotate pinning decisions and flag any headlines likely to score Low.

---

## Chapter 4: Audience Targeting: In-Market Segments, LinkedIn Profile Targeting & Remarketing

**Duration:** ~55 min
**Learning objectives:**
- Enable the Universal Event Tracking (UET) tag and verify it fires on key travel booking funnel pages
- Build in-market audience segments for travel-intent users and apply them in observation mode before switching to bid-only
- Configure LinkedIn Profile Targeting by job function and industry to reach business traveler audiences
- Create a remarketing list for cart-abandoners and set appropriate bid adjustments across Search and Audience Network campaigns

**Key concepts:** UET tag, in-market segments, observation mode, bid-only targeting, LinkedIn Profile Targeting, remarketing lists, bid adjustments, Audience Network

**Hands-on exercise:** Install and verify the UET tag on a staging travel site. Build one in-market segment (travel intent), one LinkedIn targeting layer (business traveler profile), and one cart-abandoner remarketing list. Apply all three to a test campaign in observation mode.

---

## Chapter 5: Performance Max on Microsoft Advertising: Setup, Asset Groups & AI Optimization

**Duration:** ~60 min
**Learning objectives:**
- Create a Performance Max campaign with a purchase or lead-gen conversion goal meeting the 15-20 conversion weekly budget threshold
- Build at least two asset groups segmented by travel product with compliant creative assets
- Enable the new customer acquisition goal in open beta and configure new-customer bid uplift
- Interpret Website URL, Landing Page, and Search Term reports to identify underperforming placements and refine search themes

**Key concepts:** PMax campaign structure, AI learning period, asset groups, creative asset compliance, new customer acquisition goal, PMax transparency reports, search theme refinement

**Hands-on exercise:** Create a PMax campaign for a travel brand with two asset groups (domestic flights vs international packages). Configure the new customer acquisition goal and set bid uplift. Run a mock PMax report review and flag two underperforming search themes for removal.

---

## Chapter 6: Conversion Tracking, Enhanced Conversions & Performance Reporting

**Duration:** ~45 min
**Learning objectives:**
- Set up conversion goals (page visit, booking confirmation, and micro-conversion events) linked to the UET tag
- Implement Enhanced Conversions to pass hashed first-party customer data and validate in the conversion diagnostics panel
- Create a custom report with standard performance columns at campaign and ad group level
- Use the Bid Strategy Report to identify campaigns stuck in the learning period

**Key concepts:** Conversion goal types, UET-goal linking, Enhanced Conversions, hashed first-party data, conversion diagnostics, custom reporting, Bid Strategy Report, learning period signals

**Hands-on exercise:** Configure three conversion goals for a travel booking funnel. Implement Enhanced Conversions for confirmed-booking events. Build a custom report template and identify one campaign in learning period using the Bid Strategy Report.

---

## Chapter 7: Cross-Platform Budget Allocation: Splitting Spend Between Google Ads and Microsoft Advertising

**Duration:** ~50 min
**Learning objectives:**
- Benchmark Google Ads vs Microsoft Advertising CPCs, CTRs, and CPAs using 2026 travel-sector data
- Apply the 70/30 starting split rule and define performance triggers for reallocation after a 30–60 day test
- Export comparable campaign performance into a unified view and compute incremental ROAS per channel
- Decide on a revised budget split based on desktop conversion rate share, CPA efficiency, and audience overlap

**Key concepts:** CPC/CPA benchmarking, 70/30 split rule, test-and-scale methodology, cross-platform unified reporting, incremental ROAS, reallocation triggers, audience overlap analysis

**Hands-on exercise:** Given a sample dataset of 60 days of parallel Google Ads and Microsoft Advertising performance for a travel brand, compute incremental ROAS per channel, apply the reallocation decision framework, and produce a one-page budget allocation rationale document.

---

## Capstone: Full-Funnel Microsoft Advertising Audit & Budget Pitch

Using a provided travel brand brief, learners will: audit an existing Microsoft Advertising account against the import and audience checklists from chapters 2 and 4; write a 500-word optimization report citing specific metrics from chapter 6's custom dashboard; and present a justified cross-platform budget allocation for Q3 using the framework from chapter 7. Deliverable: a Google Slides deck (5 slides) and the optimization report.
