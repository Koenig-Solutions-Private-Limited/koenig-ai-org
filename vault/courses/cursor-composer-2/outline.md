# Course outline: Cursor Composer 2 — IDE-First AI Engineering

This course provides a deep dive into Cursor Composer 2, focusing on shifting from simple AI chat interactions to comprehensive, multi-file IDE-driven engineering.

## Chapter 1: Foundations — Cursor AI Environment & Rules
- Set up Cursor for advanced AI engineering, including project rules and AGENTS.md.
- **Learning Objectives**: Configure .cursorrules, establish project context, set up AI engineering environment.
- **Duration**: 45 minutes
- **Key Concepts**: Project discipline, AI-engineering environment, .cursorrules.
- **Hands-on Exercise**: Setup a project repository with a robust `.cursorrules` file and initial `AGENTS.md`. 
  - *Time-box*: 30 min. 
  - *Success Criteria*: AI agent correctly adheres to defined coding standards and project conventions in a test file.

## Chapter 2: Mastering the Cursor Composer Interface
- Learn the foundational layout, command shortcuts, and context management tools within Cursor Composer.
- **Learning Objectives**: Navigate the Composer interface, manage context windows efficiently, use AI commands.
- **Duration**: 45 minutes
- **Key Concepts**: IDE context, AI-IDE integration, Composer UI.
- **Hands-on Exercise**: Map out and configure a project's context window. 
  - *Time-box*: 30 min. 
  - *Success Criteria*: Successfully add 5+ relevant files to the context window and verify AI understanding via a query.

## Chapter 3: Context-Aware Code Generation
- Leverage Cursor's ability to understand project structure for generating new features.
- **Learning Objectives**: Implement multi-file generation, ensure code consistency, handle project-wide dependencies.
- **Duration**: 60 minutes
- **Key Concepts**: Context scoping, dependency management, semantic code awareness.
- **Hands-on Exercise**: Generate a new micro-service component. 
  - *Time-box*: 45 min. 
  - *Success Criteria*: Component is generated, integrates correctly, and passes basic linting.

## Chapter 4: Orchestrating Multi-File Changes
- Coordinate complex changes across layers, maintaining architectural integrity.
- **Learning Objectives**: Coordinate changes across layers, leverage Composer for project-level changes.
- **Duration**: 60 minutes
- **Key Concepts**: Architectural consistency, orchestration.
- **Hands-on Exercise**: Refactor a cross-layer data model. 
  - *Time-box*: 45 min. 
  - *Success Criteria*: Models updated across DB, Service, and API layers without breaking build.

## Chapter 5: Automated Refactoring & Modernization
- Automate the process of refactoring complex legacy codebases using AI.
- **Learning Objectives**: Detect code smells, automate large-scale refactors, maintain test coverage.
- **Duration**: 60 minutes
- **Key Concepts**: Refactoring patterns, code quality metrics, automated testing.
- **Hands-on Exercise**: Refactor a legacy module to modern design patterns. 
  - *Time-box*: 45 min. 
  - *Success Criteria*: Refactoring completed, existing tests pass, and AI-suggested improvements documented.

## Chapter 6: Debugging & Error Resolution
- Utilize AI for complex debugging across interacting modules.
- **Learning Objectives**: Trace errors, generate logs/tests, interpret AI fixes.
- **Duration**: 60 minutes
- **Key Concepts**: Root cause analysis, automated debugging, log-based reasoning.
- **Hands-on Exercise**: Resolve a complex, cross-module runtime bug. 
  - *Time-box*: 45 min. 
  - *Success Criteria*: Bug is resolved, regression test is added, and fix is verified.

## Chapter 7: Advanced Prompting & Collaboration Patterns
- Refine the human-in-the-loop workflow for maximum productivity and safety.
- **Learning Objectives**: Manage AI suggestions, verify AI-generated output, prompt engineering.
- **Duration**: 60 minutes
- **Key Concepts**: Review workflows, oversight, trust-but-verify.
- **Hands-on Exercise**: Build and implement a reusable code review prompt library. 
  - *Time-box*: 45 min. 
  - *Success Criteria*: Library successfully used to conduct a code review with >80% accuracy in finding issues.

## Chapter 8: The Capstone Project — Production Feature E2E
- Synthesize all learning into a final feature implementation.
- **Learning Objectives**: Apply all course learnings to a real-world problem, document AI-first workflow.
- **Duration**: 65 minutes
- **Key Concepts**: AI-engineering strategy, production-ready implementation.
- **Hands-on Exercise**: Develop a full-scale feature implementation. 
  - *Time-box*: 60 min. 
  - *Success Criteria*: Feature is implemented, tested, and AI-driven development process documented.

## Capstone project
Develop a production-ready feature implementation and document the entire AI-driven development process used, demonstrating mastery of Cursor Composer 2 for complex engineering tasks.
